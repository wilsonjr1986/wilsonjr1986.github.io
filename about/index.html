Jarvis Assistant v2

Personal project of Johnny Wilson

Jarvis Assistant v2 is a personal AI assistant for Johnny Wilson. It runs on the owner’s own devices to help with everyday scheduling, mail, files, and related tasks using Google services the owner authorizes.

Purpose

Jarvis Assistant v2 exists so the owner can talk to one assistant that already knows their calendar, inbox, files, and routines. It is a private, single-user tool—not a public product, marketplace app, or multi-tenant service. Only the owner’s Google account is used.

What it does

After the owner signs in with Google, Jarvis Assistant v2 can help with the Google services listed below (only the scopes shown on Google’s consent screen; read-only where that is how the feature is configured):

  • Calendar — view and update events, reminders, and availability so the assistant can schedule and summarize the owner’s day.
  • Gmail — read, draft, send, and organize mail related to assistant actions the owner requests.
  • Drive — find and work with the owner’s files when a task needs documents or attachments.
  • Contacts — look up people for messaging, invitations, and scheduling.
  • Tasks — create and manage to-dos the owner asks the assistant to track.
  • Sheets — read and update spreadsheets the assistant helps maintain.
  • Photos — limited access when a feature needs media the owner selects.
  • Fitness — activity summaries when the owner enables health/fitness help.
  • YouTube — read-only information when a request is about videos or subscriptions.

How it uses Google user data

Google user data is used only to provide personal assistant features to the account owner on their own devices. Access is owner-only: there are no other end users, no customer accounts, and no public signup.

Jarvis Assistant v2 does not sell Google user data. It does not share Google user data with third parties for their independent use, advertising, or resale. Data is not used to train unrelated public models. This is a personal project operated by Johnny Wilson.

OAuth tokens stay on the owner’s private devices or owner-controlled backend. The owner can disconnect Google at any time from Google Account third-party access or from Jarvis Assistant v2 settings.
