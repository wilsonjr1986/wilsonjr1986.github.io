Privacy Policy

Last updated: September 20, 2026

Who we are

Jarvis Assistant v2 (“JJ”) is a personal AI assistant operated by Johnny Wilson (wilsonjr1986@gmail.com). It is intended for personal use by the owner, not as a public commercial multi-user service.

Google user data we access

When you connect Google, JJ may request access (via OAuth) to Google user data needed for the features you use, such as:

  • Google Calendar — read/write events and reminders
  • Gmail — read, send, and manage mail related to assistant actions
  • Google Drive & Sheets — read/write files the assistant helps with
  • Contacts — look up people for messaging and scheduling
  • Tasks — manage to-dos
  • Fitness — activity summaries when enabled
  • Photos — limited access when a feature needs media you select
  • YouTube — read-only information when relevant

Exact scopes are those configured in the Google Cloud project Jarvis Project - Calendar and shown on Google’s consent screen.

How we use Google user data

Google user data is used only to provide personal assistant features to the account owner: scheduling, email and message help, file lookup, reminders, and related automation the owner enables. We do not sell Google user data. We do not use Google user data for advertising. We do not transfer Google user data to unrelated third parties for their independent use.

How we store Google user data

OAuth tokens and related data are stored on the owner’s private devices / private backend for the assistant (local and owner-controlled servers). Data retention follows what the owner keeps on those systems; the owner may disconnect Google and delete local data at any time.

Sharing

Google user data is not shared with third parties except as required to operate the assistant for the owner (for example, Google APIs themselves) or if required by law.

How to revoke access

You can revoke JJ’s access at any time in your Google Account: Google Account → Third-party access (or Security → Third-party apps with account access). You can also reconnect or disconnect from within Jarvis Assistant v2 under Settings → Integrations.
